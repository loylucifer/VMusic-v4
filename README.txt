1) Make a new GitHub repo, upload ALL files of this folder (including hidden .github).
2) Actions -> "Build APK" -> download artifact "VMusic-apk" -> install app-debug.apk.
Wallpapers (7) are already bundled in app/src/main/assets/wallpapers/ - add more there or inside the app (Settings -> Look -> Wallpapers).
App icon is app/src/main/res/drawable/ic_launcher.png (replace it with your own picture any time).
